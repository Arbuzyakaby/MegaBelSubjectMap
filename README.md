# Интерактивная карта субъектов Беларуси

Премиальная интерактивная карта 6 областей, г. Минска и 118 районов: карточка у каждого региона и района, интересные факты, свежие официальные данные, раскраска-рейтинг по показателям и режим «Рельеф».

## Что нового в 2.0

- **118 районов.** Переключатель «Области | Районы» над картой. В режиме районов каждый район залит оттенком цвета своей области (или тепловой шкалой по показателю), поверх — толстые границы областей; клик открывает короткую карточку района: площадь, население (≈), плотность с местом в стране «№N из 118», доля в населении области, переход ← → по районам той же области. Рейтинг показывает все 118 районов с фильтром по области. В режиме областей у выбранной области проступают границы её районов, а в карточке области есть список районов со ссылками.
- **Режим «Рельеф».** Переключатель «Карта | Рельеф»: под контурами — отмывка рельефа с гипсометрической раскраской 80–345 м (вертикальное преувеличение ×10 — страна равнинная), маркеры высшей (Дзержинская гора, 345 м) и низшей (урез Немана, ≈80 м) точек, шкала высот в легенде. Клики и карточки продолжают работать.
- **Интерфейс на 20% компактнее** (`zoom: 0.8`; на телефонах — 0.9, чтобы не мельчить тач-цели).
- **Новая геометрия:** границы из geoBoundaries; области собираются из районов, поэтому их границы совпадают идеально.

## Возможности

- **Карта** — анимированная прорисовка контуров, подсветка при наведении, приближение к выбранному региону, клавиатурная навигация (Tab / Enter / Esc).
- **Раскраска по показателю** — население, плотность, площадь, зарплата, доля горожан, число районов. Тепловая шкала от синего (минимум) до красного (максимум), лидер пульсирует, для показателей с разрывом на порядки (плотность, площадь) используется логарифмическая шкала.
- **Рейтинг** — список регионов с анимированной пересортировкой, переключением направления сортировки и сводкой (значение по стране, лидер, разрыв между первым и последним).
- **Карточка района** — область, центр, площадь, население (оценка), плотность, место среди 118 районов, доля в населении области; пометка, если население указано без города областного подчинения.
- **Карточка региона** — описание, 6 показателей с местом в рейтинге и сравнением со средним по стране, структура населения (город/село), доля в населении страны, 6–7 интересных фактов, достопримечательности, крупные города и предприятия. На телефоне открывается как bottom sheet со свайпом вниз.
- **RU / BE** — полный перевод интерфейса и контента на белорусский.
- **Тёмная и светлая темы**, поддержка `prefers-reduced-motion`.

### Оговорки

- **Население районов — оценка.** Официальная статистика по районам в среде сборки была недоступна, поэтому значения взяты по памяти (перепись 2019 г. и последующие оценки) и затем нормированы внутри каждой области так, чтобы сумма районов и городов областного подчинения совпала с данными Белстата по области на 01.01.2026. В интерфейсе такие числа помечены «≈». Для районов вокруг городов областного подчинения (Брест, Барановичи, Пинск, Витебск, Полоцк, Новополоцк, Гомель, Гродно, Жодино, Могилёв, Бобруйск) население указано без города — об этом есть строка в карточке.
- **Граница Дрибинского района приблизительная.** В geoBoundaries Дрибинский район слит с Горецким; скрипт отрезает его южную часть прямой линией, подобранной так, чтобы площадь составила ≈634 км².
- «Окно» у северо-восточной границы Гродненской области — не ошибка, а Девенишский выступ территории Литвы.

Цифры областей лежат в `src/data/regions.ts`, районов — в `scripts/source/districts.table.mjs` (из неё генерируется `src/data/districts.ts`).

## Запуск

```bash
npm install
npm run dev       # локальный сервер разработки
npm run build     # проверка типов + продакшн-сборка в dist/
npm run preview   # просмотр собранной версии
```

Геометрия, данные районов и подложка рельефа уже подготовлены и лежат в репозитории. Пересобрать их можно так:

```bash
npm run build:geo      # районы + области → src/data/belarus.topo.json (со сверкой площадей)
npm run gen:districts  # таблица районов → src/data/districts.ts (нормировка населения)
npm run build:relief   # тайлы высот → src/assets/relief.webp (тайлы кэшируются в scripts/.cache)
```

## Публикация

Сайт публикуется автоматически: при каждом пуше в основную ветку репозитория workflow `.github/workflows/deploy.yml` собирает проект и выкладывает результат в ветку `gh-pages`, откуда его раздаёт GitHub Pages. Запустить деплой вручную можно во вкладке **Actions → Deploy to GitHub Pages → Run workflow**.

Адрес сайта: https://arbuzyakaby.github.io/MegaBelSubjectMap/
