# Интерактивная карта субъектов Беларуси

Премиальная интерактивная карта 6 областей и г. Минска: карточка у каждого региона, интересные факты, свежие официальные данные и раскраска-рейтинг по показателям.

## Возможности

- **Карта** — анимированная прорисовка контуров, подсветка при наведении, приближение к выбранному региону, клавиатурная навигация (Tab / Enter / Esc).
- **Раскраска по показателю** — население, плотность, площадь, зарплата, доля горожан, число районов. Тепловая шкала от синего (минимум) до красного (максимум), лидер пульсирует, для показателей с разрывом на порядки (плотность, площадь) используется логарифмическая шкала.
- **Рейтинг** — список регионов с анимированной пересортировкой, переключением направления сортировки и сводкой (значение по стране, лидер, разрыв между первым и последним).
- **Карточка региона** — описание, 6 показателей с местом в рейтинге и сравнением со средним по стране, структура населения (город/село), доля в населении страны, 6–7 интересных фактов, достопримечательности, крупные города и предприятия. На телефоне открывается как bottom sheet со свайпом вниз.
- **RU / BE** — полный перевод интерфейса и контента на белорусский.
- **Тёмная и светлая темы**, поддержка `prefers-reduced-motion`.

## Данные

|---|---|---|
| Население, городское и сельское | Белстат | на 1 января 2026 г. |
| Номинальная начисленная средняя зарплата | Белстат | август 2026 г. |
| Площадь | официальные данные (округлено до км²) | — |
| Границы регионов | [Natural Earth](https://www.naturalearthdata.com/) 1:10m admin-1, общественное достояние | — |

Суммы по регионам сверены с итогами по стране: 9 056 080 человек, из них 7 157 309 горожан и 1 898 771 сельский житель.

Все цифры лежат в `src/data/regions.ts` — чтобы обновить данные, достаточно поменять значения там.

## Запуск

```bash
npm install
npm run dev       # локальный сервер разработки
npm run build     # проверка типов + продакшн-сборка в dist/
npm run preview   # просмотр собранной версии
```

Геометрия уже подготовлена (`src/data/belarus.topo.json`). Пересобрать её из исходника можно командой `npm run build:geo`.

## Публикация

Workflow `.github/workflows/deploy.yml` собирает сайт и публикует его на GitHub Pages при пуше в `main`. Для этого в настройках репозитория включите **Settings → Pages → Source: GitHub Actions**. Адрес сайта: `https://<пользователь>.github.io/MegaBelSubjectMap/`.

## Стек

React 18, TypeScript, Vite, Framer Motion, d3-geo / d3-scale, TopoJSON.
